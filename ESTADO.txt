    "punto" / "coma" / "dos puntos" / "punto y coma"

                            con Ctrl+Z: deshacer en una ventana ajena puede

  LO ESCRIBE WIN+H, no el asistente: es el motor que de verdad te entiende, y
  aquí su pega no existe (el foco TIENE que estar en tu ventana, que es donde
  se escribe). El asistente abre Win+H solo, después de callarse -si lo abriera

  mientras dictas: no hay forma de apartarlo. Al terminar se CIERRA de
  verdad (ver abajo, "la ventanita de Windows").

EL CEREBRO DE FUERA (nuevo, 12/09): la API de Claude para ENTENDER, opencode
  para HACER. Lo que se le pide al modelo casi siempre es traducir una frase a
  una orden conocida o contestar algo corto, y para eso opencode es un camión
  para llevar una carta: monta un agente con herramientas y tarda 13-160 s. Una
  llamada directa a la API tarda ~1 s (medido).
    traducir una frase nueva   -> Claude Haiku 4.5  (~1 s)
    preguntas habladas         -> Claude Opus 5     (~2 s)
    tareas de verdad           -> opencode, como siempre
  La clave se lee de la variable de entorno ANTHROPIC_API_KEY (del usuario);
  NUNCA viaja por la línea de comandos, donde la vería cualquiera que mire la
  lista de procesos. Ajustes: config.json -> modelo (usarClaude, rapido, bueno).
  Coste: cada traducción son ~400 tokens de entrada, o sea unos 0,0004 $. Con
  5 $ de saldo salen del orden de doce mil órdenes.
  SI LA API FALLA, la orden NO se pierde: se rehace con opencode. Y si el error
  es de los que no se arreglan reintentando (sin saldo, clave mala), se deja de
  intentar hasta el siguiente arranque, para no añadir un segundo de espera a
  cada orden para nada. El motivo exacto queda en assistant.log.

QUÉ CAMBIÓ EL 11/09 (por qué hacía cosas solo, y qué lo impide ahora)
  El micrófono capta el sonido de tus altavoces. Con un vídeo o un juego
  sonando, Whisper transcribía ese audio y el asistente lo tomaba por

     CONTUVIERA lo dicho, así que el artículo más común del idioma valía. Y

     el 40 % del título.
  2. El catálogo recitado. A Whisper se le pasan tus apps y juegos como
     pistas; ante ruido devuelve esos nombres en fila ('SILENT BREATH, PEAK,
     Hollow Knight, Outlast 2...') y se abrían los cinco. Una enumeración sin
     verbo ya no es una orden.

     Ahora para decir que sí hay que decirlo.
  4. El repaso con el modelo preciso se saltaba el filtro de ruido, y ese
     modelo, ante un ruido, se inventó 'SILENT BREATH' y abrió el juego en
     mitad de una partida. Ahora va después del filtro, y si lo repasado no
     se parece en nada a lo que se oyó primero, se descarta por invención.
